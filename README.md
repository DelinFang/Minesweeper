# Minesweeper
Working minesweeper game played through terminal in Java. 
Download all 3 files to successfully run. This game offers 3 difficulties, easy, medium, and hard. Each difficulty corresponds to a 9x9, 16x16, and 16x30 board respectively including coordinate 0,0. 
When choosing a coordinate to uncover or flag, keep in mind that the order will be row, column. For example, on hard difficulty, the coordinate 15,29 will uncover the bottom right.
